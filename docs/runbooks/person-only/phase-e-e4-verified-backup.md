## If something goes wrong
- **Nothing to roll back.** E4 writes only under `$E4` and `$DRILL`; the live DB is read through the online backup API (`phase-c-backup.sh:6-9,159`; `backup.mjs:86-91`), the app bundle and SSD trees are only read by tar. Abort = stop; nothing on disk changed. Keep `$E4` unless the run was a FAIL you are redoing from scratch.
- **`integrity_check` FAIL in step 5 or 6:** `sqlite3 -readonly "$LIVE/lariat.db" 'PRAGMA integrity_check;'` — if not `ok` on the live DB, that is a C4 integrity alarm (`c4-backup-restore-drill.md:46`): stop, keep the logs and `$E4`, hand to an agent in chat. Do not "repair" the live DB.
- **`row count <table> (want > 0)` FAIL:** roster resolves as the first of `staff` / `entities_employees` / `sevenshifts_users` (`phase-c-backup.sh:96-116`; live DB has `entities_employees`, `sevenshifts_users`, `locations`, `audit_events`, measured 2026-09-02). Rerun step 6 with `LARIAT_VERIFY_TABLES="entities_employees locations audit_events"` and say so in the record.
- **SSD unmounts mid-copy** (`tar: … No such file or directory`, or `test -d ~/Dev` → 1): every tarball written after the unmount is partial — delete those, remount, redo them from step 7, re-checksum. Never trust a tarball that was mid-write when the drive went away.
- **Disk fills** (tar exits non-zero, `df -h ~` near 0): remove the partial tarball; pick a bigger destination that is **not** the SSD being cleaned; re-export `E4` and redo from step 4.
- **A target is `unknown`:** back it up, but it never enters an E5 batch (`phase-d-e-checklists.md:45`). A target missing on disk goes back to E3; a target that is a load-bearing path (`:40-42`) means E2 is not done — stop.
- **Any step wants `rm`, `mv`, `rsync --delete` or to "clean up" a duplicate:** that is E5 — stop; it needs its own per-batch confirmation (`phase-e-consolidation.md:19,24-26`).
- **PII:** never extract a `lariat-data-sources` or pre-scrub copy inside any checkout; `$DRILL` must stay outside the repo tree (`CLAUDE.md:47,70-73`). Never include `$LIVE/keys/` in any tarball (`docs/OPERATIONS.md:106`).
- Anything touching HACCP or a surface in `docs/PROTECTED_CONTRACTS.md` surfaces: stop and report in chat; do not improvise.
