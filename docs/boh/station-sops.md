## Dish pit

**Shift (5:00 in):** break down prep boxes · wash prep dishes · silverware + silver bullets for the rush · fresh liner
**6:30–7:00:** service dishes as they land · 1/6, 1/3, ½ pans back for station flip · **8:00:** plates + bullets cycling

**Machine:** seat scrap screens + drain plug, fill, one empty cycle to posted temp, check detergent/rinse-aid/sanitizer lines. Every rack: scrape → pre-rinse → rack right (plates in pegs, cups face-down, pans angled, silverware loose, presoak crusted) → full racks only in rush → air dry. Clear scrap screens hourly · change cloudy water · sanitizer strip once/shift (fail → tell manager, switch to three-sink). **Never in machine:** knives (hand wash, return immediately), wood, nonstick.
**Three-sink:** wash hot + detergent → rinse → sanitize (labeled concentration, test strip) → air dry.
**Rush priority:** line's pans → bullets/silverware → plates → everything else.
**Chemical safety:** never mix chemicals · gloves for bleach/boards · apron at machine · squeegee wet floor immediately · know the SDS binder · report every cut/burn same shift.

**Close (8:30–10):** remaining pans/spatulas/fry baskets · silverware for rolling · sinks + drains · bleach cutting boards · drain + power off machine · sweep + trash · dump expo hot well · scrub line with floor sanitizer + deck brush · squeegee to floor drain
