If Lariat is down

Do these in order. Keep cooking — use the paper packet while you fix it.

1 · Is the app really down?

On this Mac, open http://localhost:3000 in a browser.

If it loads here but not on another computer, use this Mac's address:

http:// :3000

2 · Restart the app

Open Terminal and type this one line:

bash ~/lariat_dev/Lariat/scripts/start-hub.sh

It prints “Lariat is up” when it's ready — about 10 seconds. Then reload the browser.

You can close the Terminal window afterward; the app keeps running. If it says it's already running, the app is fine — the problem is somewhere else.

3 · Assistant (LaRi) not answering?

The boards still work without it. To bring it back, in Terminal:

~/.local/bin/ollama serve

Until it's fixed: write temps, 86s, and counts on the printed packet. Enter them in Lariat after.
