# August 2026 — Daily · Weekly · Monthly checklists

House cleaning & side-work packet for **August 2026**.  
Daily runs every close. Weekly runs Wed→Sun. Monthly lands on **Sun Aug 16** (mid-month slow Sunday); if you miss it, make it up **Sun Aug 23**.

Live ticks also land on **/day-plan** when due.

## Daily (every close — all August)

- [ ] Restock / top-fill station
- [ ] Flip station
- [ ] Refill sauce + squeeze bottles
- [ ] Wrap line
- [ ] Wipe cutting boards
- [ ] Sanitize prep sink, knives, surfaces
- [ ] Clean stovetop / char / flat top (grill)
- [ ] Season flat top (grill)
- [ ] Filter fryer oil (fry)
- [ ] Ice-bath + wrap steam well (expo)

### House

- [ ] Equipment off (steam well, grill, fryer, oven)
- [ ] Restock reach-in
- [ ] Wipe stainless
- [ ] Dishes washed + machine drained
- [ ] Sweep + mop; empty mop bucket
- [ ] Gas to wok off
- [ ] Hood vent off
- [ ] Trash out · rag buckets emptied

**Sign-off:** closer initials + time on the day plan / cleaning log.
